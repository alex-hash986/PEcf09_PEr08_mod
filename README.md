# 🤖 RAG-ассистент с SQLite-кэшированием, метриками и Telegram-ботом

Интеллектуальный консультант по базе знаний на базе **OpenAI API (`gpt-4o-mini` + `text-embedding-3-small`)** и векторной БД **ChromaDB**. Система оснащена локальным SQLite-кэшем, полноценным логированием взаимодействий (`logs.db`), автоматической оценкой качества по фреймворку **RAGAS** и интерфейсом в **Telegram**.

## 💼 Бизнес-ценность и ключевые метрики

* **Высокая точность ответов (94% по RAGAS):** валидация пайплайна на контрольном датасете показала **Context Precision ~0.95** и **Faithfulness ~0.85**, что минимизирует галлюцинации за счёт строгого ответа по контексту.
* **Снижение задержки (Latency) и затрат на API:** локальный SQLite-кэш (SHA-256 по нормализованному запросу) возвращает повторные ответы за **< 5 мс** вместо 1500–2500 мс при обращении к LLM, сокращая расходы на токены на повторяющихся вопросах в 2+ раза.
* **Полная наблюдаемость (Observability):** каждый запрос фиксируется в `logs.db` с замером времени ответа (`response_time_ms`), статусом кэша (`from_cache`), тематическим тегом и обезличенным `user_id` (SHA-256).

## 🚀 Функциональность

* **Умный семантический чанкинг:** разбиение текста (до 500 символов) по границам абзацев и предложений с 20% перекрытием (`overlap=100`).
* **SQLite-кэширование (`cache.py`):** хранение пар «запрос — ответ — контекст» с мгновенным поиском по SHA-256 хешу.
* **Логирование и аналитика (`db_logger.py`):** запись истории диалогов в `logs.db`, автоматическое тегирование тем (`rag_architecture`, `prompt_engineering`, `fine_tuning`, `ml_basics`), ротация старых записей и экспорт в CSV.
* **Telegram-бот (`telegram_bot.py`):**
  * `/start`, `/help` — навигация и примеры запросов;
  * `/stats` — сводка по чанкам, Cache Hit Rate, средней скорости ответа (с кэшем и без) и распределению тегов;
  * `/logs` — мгновенная выгрузка истории запросов пользователя в формате `.csv`;
  * `/cleanup` — очистка логов старше 30 дней.
* **Автоматическая оценка качества (`evaluate_ragas.py`):** расчёт метрик *Faithfulness* и *Context Precision* через RAGAS.
